# STUDY SYNC - B.Tech Academic Hub 🎓⚡

A modern, responsive, and complete academic web application designed specifically for B.Tech engineering scholars (Semesters 1 to 8)

---

## 🌟 Complete Features Included

1. **User Authentication & Streaks:**
   - Sign in with Email/Password or use the **1-Click Demo Login** button (Student: Aarav Sharma - B.Tech CSE).
   - Register new student profiles with Branch (CSE, IT, ECE, EE, ME, CE, AIML) and Year (1st to 4th).
   - Real-time study streak counter (`🔥 8d Streak`) that increases with daily logins and study sprints.
   - User profile dashboard showing uploaded notes, saved papers, total focus hours, and activity logs.

2. **B.Tech Notes Sharing System:**
   - Pre-loaded with authentic study notes:
     - *Data Structures & Algorithms (Trees, Graphs, Dijkstra, DP)* - CSE/IT Sem 3
     - *Operating Systems (Deadlocks, Banker's Algorithm, Paging)* - CSE/IT Sem 4
     - *DBMS (Normalization 1NF-BCNF, ACID Transactions)* - IT Sem 4
     - *Computer Networks (OSI Model, TCP Handshake, Subnetting)* - CSE Sem 5
     - *Digital Communication (Nyquist Sampling, PCM, Modulation)* - ECE Sem 5
     - *Thermodynamics (Rankine Cycle, Carnot, Entropy)* - ME Sem 3
   - Real-time search by topic, subject, or keywords.
   - Branch filter pills (CSE, IT, ECE, ME, EE, CE) and Semester filter pills (Sem 1 to Sem 8).
   - Note Reader with Markdown preview, Upvote counter, Comments discussion feed, and direct link copy.
   - Upload & Publish notes modal (+50 Reputation).

3. **University PYQ Archive:**
   - Previous Year Question papers organized by Subject, Semester, and Year (2024, 2023, 2022).
   - Instant PDF download link and bookmarking feature.

4. **10-Question Timed Mock Tests:**
   - Dedicated subject mocks (DSA Mastery Test, Operating Systems Mock, etc.).
   - Interactive 15-minute countdown clock.
   - Question navigation palette.
   - Instant score evaluation and passing qualification badge.
   - Detailed answer key with in-depth conceptual explanations for every question.

5. **Pomodoro Study Focus Timer:**
   - 25m Focus / 5m Break / 15m Long Break cycles.
   - Built-in Web Audio Bell Chime alert (synthesized natively in-browser without external MP3 files).
   - Automatically credits study minutes and extends your daily study streak.

6. **Modern UI & Themes:**
   - Sleek Dark Mode and Light Mode with instant toggle and persistence.
   - Fully responsive for mobile, tablets, and desktop.
